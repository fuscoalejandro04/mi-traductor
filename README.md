# 📄 Traductor de PDF (Inglés → Español)

Aplicación web creada con **Streamlit** que permite subir un PDF en inglés, extraer su texto, traducirlo al español y descargar el resultado como un nuevo PDF.

## ✨ Características

- Subida de archivos PDF.
- Extracción de texto de PDFs (funciona con PDFs basados en texto).
- Traducción automática del inglés al español usando Google Translate (vía `deep-translator`).
- Vista previa del texto original y traducido.
- Descarga del texto traducido en formato PDF.
